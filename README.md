# Student Portal

A simple and responsive Student Portal created using **HTML** and **CSS**. This project was built to practice fundamental web development concepts such as semantic HTML, styling with CSS, tables, forms, and page layout.

## Features

- Responsive and clean user interface
- Navigation bar for easy access
- Student profile section
- Skills overview
- Weekly class schedule
- Course registration form
- Styled tables, buttons, badges, and form elements

## Technologies Used

- HTML5
- CSS3
